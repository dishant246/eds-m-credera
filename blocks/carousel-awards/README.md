# carousel-awards

Custom **carousel** block. Purpose: gallery.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: container + repeating award-badge image items, horizontal scroll with prev/next.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
