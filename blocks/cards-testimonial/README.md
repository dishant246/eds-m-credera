# cards-testimonial

Custom **cards** block. Purpose: testimonial.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: container + repeating testimonial cards (portrait + prompt label + quote + name + role), horizontal scroll, click-to-reveal.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
