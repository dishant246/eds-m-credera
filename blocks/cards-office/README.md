# cards-office

Custom **cards** block. Purpose: directory.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: container + repeating office cards (location icon + name + full address + 'View Office' link), horizontal scroll.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
